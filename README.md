# Mobile Butler

모바일 버틀러 프로젝트입니다.
모바일에서 개인 업무를 돕는 버틀러 앱입니다.

현재 프로젝트를 준비하고 있습니다. 기능과 실행 방법은 개발이 진행되면 추가할 예정입니다.

## 참여하기

누구나 PR을 보낼 수 있는 오픈 협업 프로젝트입니다. 작업을 시작하기 전에 아래 두 문서를 읽어주세요.

* [기여 양식 및 규칙](docs/contribute_rules.md) — 브랜치 전략, 커밋 메시지, 작업 시작 전 확인할 것
* [PR 룰](docs/PR_rules.md) — PR 말머리와 본문 양식, 리뷰·머지 절차

모든 작업은 `dev` 브랜치를 기준으로 진행하고 PR도 `dev`로 보냅니다. `master`는 실제 서비스로 나갈 코드만 모읍니다.

그 외 기획·설계 문서는 [docs](docs/README.md)에 정리되어 있습니다.
