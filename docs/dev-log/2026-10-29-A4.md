# 도메인 규칙과 단위 테스트 구현 (A-4)

- 일자: 2026-11-03
- 작업자: yuhan3958
- 관련: #48 / PR #미정

## 한 일

- 누적형 목표의 남은 분량과 마감일까지의 남은 일수를 바탕으로 일일 권장량을 자동 계산하도록 구현했습니다. 오늘 기록은 계산에서 제외해 하루 동안 권장량이 유지되도록 했습니다.
- 날짜별 기록량을 합산해 `FULL`, `PARTIAL`, `NONE` 상태를 판정하고, 오늘의 기록 여부를 별도로 구분하도록 구현했습니다.
- 전체 목표 진행률, 연속 기록 일수, 최근 N일 중 기록한 날짜 수를 계산하는 기능을 추가했습니다.
- 목표 달성 여부와 마감일 경과 여부를 평가하고, 목표의 저장 상태와 날짜상 진행 단계를 분리했습니다.
- 목표 달성 시 자동 완료, 마감 경과 시 최초 1회 알림, 수동 종료, 완료 취소 등의 상태 전이 규칙을 구현했습니다.
- 마감일이 지난 목표도 `ACTIVE` 상태를 유지하며, 사용자가 새로운 마감일을 지정해 기존 기록을 보존한 채 계속 진행할 수 있도록 했습니다.
- 계산 및 상태 전이 로직을 Room과 UI에 의존하지 않는 순수 Kotlin 코드로 분리하고, 각 기능에 대한 JUnit 단위 테스트를 추가했습니다.
