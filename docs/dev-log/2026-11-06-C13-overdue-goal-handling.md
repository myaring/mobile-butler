# [C-13] 마감 지난 목표 팝업, 배너 및 상태 전이 처리

- 일자: 2026-11-06
- 작업자: Aetherx86
- 관련: #80

## 한 일

- 마감 지난 목표 발생 시 1회 노출되는 `OverdueGoalDialog` 구현
- 마감 지난 목표 카드에 상시 노출되는 `OverdueGoalBanner` 구현
- 실패, 미달, 탈락 등의 부정적 표현을 배제하고 진행 분량 중심의 긍정적 안내 문구 적용
- 마감 당일(D-Day)은 마감 지난 목표로 판정하지 않고 당일로 정상 유지 처리
- 이어서 하기(`GoalEvent.Continue`) 시 마감일 갱신 및 `overdueNoticeShown` 초기화 처리
- 여기서 마무리(`GoalEvent.Finish`) 시 `COMPLETED` 상태 및 `DEADLINE` 사유 지정
- 0으로 나누기 방어 및 도메인 전이 규칙 단위 테스트 9개 추가 (전체 통과)

## 알게 된 것 / 막힌 것

- 마감 지난 목표 상태는 일회성 다이얼로그(`overdueNoticeShown`)와 지속형 배너의 두 단계 UX로 분리하여 사용자가 부담을 느끼지 않고 일정을 재조정하거나 깔끔하게 마무리할 수 있도록 설계되었습니다.
- 분모가 0이 되는 날짜 계산 예외 상황을 방어하고, 부정적인 피드백 대신 동기부여를 유지하도록 유도하는 UX 가이드라인을 엄격히 준수했습니다.
