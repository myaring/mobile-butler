# [B-3] MbProgressBar 구현

- 일자: 2026-11-06
- 작업자: Aetherx86
- 관련: #58

## 한 일

- 0.0f..1.0f 비율을 받아 트랙(미완료 영역)과 채움(완료 영역)을 그리는 공용 프로그레스 바 `MbProgressBar` 구현
- 스크린 리더 지원을 위한 `contentDescription` 및 `progressBarRangeInfo` 접근성 시맨틱 적용
- 0 미만 및 1 초과 진행률에 대한 자동 클램프 처리
- `MbProgressBarTest` 단위 테스트 작성 및 통과 확인

## 알게 된 것 / 막힌 것

- 접근성을 고려하여 색상뿐만 아니라 스크린 리더용 설명 텍스트를 필수 매개변수로 지정함으로써 모든 사용자가 진행 상태를 파악할 수 있도록 했습니다.
