## 한 일

- `GoalCreationValidator`: 이름 필수 및 길이, 단위, 전체 분량 정수만 허용, 과거 마감일 차단 검증 규칙 구현
- `GoalCreationTab`: 누적형 목표 생성 화면 구현 (이름, 단위, 정수 분량, 시작/마감일 입력 및 빠른 기간 선택 버튼)
- 실시간 하루 분량 미리보기: `PacingCalculator`를 연동하여 입력에 따른 일일 권장량 실시간 계산 표시
- `GoalScreenViewModel`: 목표 생성(`createGoal`) 및 목표 탭 목록(`GoalListTab`) 연동 처리
- 단위 테스트 작성: 정수 입력 검증, 0 이하 분량 차단, 과거 마감일 차단, ViewModel 생성 흐름, 이모지 미포함 검증 (14개 테스트)

## 알게 된 것 / 막힌 것

- 정수 분량 입력을 강제하기 위해 `rawTargetAmount`에 소수점 입력 시 즉시 안내 메시지를 제공하고 숫자 키패드(`KeyboardType.Number`)를 적용함.
- 누적형 이외의 목표 유형(줄이기, 빈도, 도달)은 비활성화 및 "준비 중" 라벨로 명확히 사용자에게 전달하도록 구성함.
