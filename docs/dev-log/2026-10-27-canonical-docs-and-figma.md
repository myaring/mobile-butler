- 정본 두 문서 모두 항목마다 **확정 / 임시 / 미정**을 붙이고, 미정에는 논의 중인 이슈를 링크했습니다. 이슈가 없던 미정 항목(기기 시간대가 바뀌었을 때의 기록 날짜)은 #52로 새로 열었습니다.

**결정은 저장하고, 날짜로 알 수 있는 것은 계산한다 (#39)**

- 마감이 지났는지는 저장하지 않고 `dueDate`와 오늘 날짜로 계산합니다. 그래서 자정에 상태를 바꾸는 백그라운드 작업이 필요 없습니다.
- `ARCHIVED`를 바로 지우지 않은 이유: enum을 이름 문자열로 저장하므로 값을 지우면 DB 마이그레이션이 필요합니다.

**문서끼리 어긋난 곳**

- #39 상태 전이표 원문의 6행 오타(`COMPELTED`)와 6·8행 `endedAt`("마감일")을 정본에서 "사용자가 고른 날"로 고쳤습니다. 마감일은 `dueDate`에 이미 있기 때문입니다.
- 되돌리기 규칙이 #39(보관함 상세, 기간 제한 없음)와 #45(완료 직후 스낵바에서만)에서 다릅니다. #45가 #44에 막혀 있어 정본에는 미정으로 두고 두 안을 비교해 두었습니다.
- `design.md`에서 확정으로 적었던 두 곳을 다른 문서에 맞췄습니다. 마감 지남 팝업은 #44의 `overdueNoticeShown`에 따라 "처음 한 번만 팝업, 그 뒤는 카드 버튼"으로, 보관함 목표 삭제는 "기능 없음"에서 미정(#48)으로 고쳤습니다.

**Figma**

- 색 변수를 두 단으로 나눴습니다: `MB Palette`(실제 색, 코드 이름 `Mb...`) → `MB Color`(M3 역할, 별칭). 화면은 역할 변수만 쓰므로 팔레트 값 하나만 바꾸면 전 화면에 반영됩니다.
- 팝업 화면은 어두운 배경까지 그린 전체 화면이라 "Overlay" 대신 "Navigate to"로 연결했습니다.
- 오토 레이아웃 프레임 안의 레이어는 스크롤 때 "고정"을 고를 수 없습니다. 목표 더보기 화면은 화면 높이를 그대로 두고 목록 영역(`Content · LazyColumn`)만 세로 스크롤하게 했습니다.
- 프로토타입에서 누르는 영역은 연결을 건 레이어 크기입니다. `자세히` 버튼이 71×24로 최소 터치 높이 48dp보다 낮다는 것을 이때 알았습니다.

**git**

- 브랜치를 옮기려고 stash를 복원할 때 `git stash apply --index`를 쓰면 `UI.md` 이동이 스테이징된 채로 돌아옵니다. 그 상태로 다른 파일만 `git add`해서 커밋하면 이동이 같이 딸려 들어갑니다. 커밋 전에 `git diff --cached --stat`으로 확인해야 합니다.
