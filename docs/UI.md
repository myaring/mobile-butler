## 문서 안내

이 문서는 모바일 집사 어플리케이션의 화면 구성과 동작을 참여자 모두가 같은 기준으로 볼 수 있게 정리한 화면설계서입니다.

| 항목      | 내용                                                        |
|-----------|-------------------------------------------------------------|
| 읽는 대상 | 개발, 디자인, 기획 참여자 (비개발자 포함)                   |
| 기준 시안 | 남색 기본형                                                 |
| 작성 범위 | 하단 4개 탭                                                 |
| 예시 값   | 시안의 날짜 (10월 20일) 와 수치는 모두 예시                 |
| 읽는 순서 | 공통 규칙, 화면 목록, 탭별 설명, 공통 컴포넌트, (미정 사항) |

상태 표기는 세 가지입니다.

- 반영: 기획자가 정했고 시안에 들어간 내용.
- 제안: 시안을 만들며 추가한 안. 합의가 필요함.
- 미정: 논의 및 결정이 필요한 사안.

## 공통 규칙

모든 화면에 같은 규칙이 적용됩니다.

| 항목           | 규칙                                                                                                   | 상태 |
|----------------|--------------------------------------------------------------------------------------------------------|------|
| 기록 칸 상태   | 한 날 / 넘긴 날 두 가지. 일부만 달성한 날도 한 날로 표시합니다.                                        | 반영 |
| 한 날의 뜻     | 그 목표의 그날 몫을 기록한 날. 줄이기 목표는 지킨 날, 일/주간 목표는 활동한 날                         | 반영 |
| 오늘 칸        | 하루가 끝나기 전에 못 채운 목표도 한 날로 두고 칸을 채워 줍니다.                                       | 반영 |
| 넘긴 날 칸     | 일/주간 목표를 기록하지 않은 날, 또는 줄이기 목표를 지키지 못한 날입니다. 칸의 색상을 채우지 않습니다. | 반영 |
| 최근 14일 기록 | 선택한 목표 하나의 최근 14일 기록을 보여 줍니다. 마지막 칸이 오늘입니다.                               | 반영 |
| 하단 탭        | 오늘, 목표, 일정, 설정 4개. 현재 탭을 다른 색상으로 강조합니다.                                        | 반영 |

최근 14일 기록의 경우, 해당사항이 없는 목표를 선택할 시 유동적으로 내용이 바뀔 수 있습니다 (제안)

목표는 종류에 따라 기록 방식이 다릅니다. 시안에 쓴 예시 목표 5가지는 다음과 같습니다.

| 예시 목표            | 종류   | 방향         | 기준 기간 | 기록 방법                              |
|----------------------|--------|--------------|-----------|----------------------------------------|
| 먀의 투쟁 읽기       | 누적형 | 늘리기(UP)   | 하루      | 읽은 쪽수 입력                         |
| 금연                 | 반복형 | 줄이기(DOWN) | 하루      | 피운 날만 기록, 기본값은 '피우지 않음' |
| 주 3회 운동          | 빈도형 | 늘리기(UP)   | 한 주     | 했을 때 한 번씩 기록                   |
| 카페인 하루 2잔 이하 | 반복형 | 줄이기(DOWN) | 하루      | 마신 잔 수 기록                        |
| 체중 감량            | 도달형 | 줄이기(DOWN) | 한 주     | 체중 입력                              |

## 화면 구성

앱은 하단 탭 4개(오늘, 목표, 일정, 설정)로 나뉘며, 시안이 있는 화면은 설정을 제외한 탭 3개입니다.

| ID    | 화면              | 탭              | 역할                                   | 시안 |
|-------|-------------------|-----------------|----------------------------------------|------|
| T-01  | 오늘              | 오늘            | 오늘 할 목표를 확인하고 바로 기록      | A    |
| T-02  | 집사 대사창       | 오늘 (오버레이) | 기록 직후 문구를 보여 줌               | A    |
| G-01  | 목표 목록         | 목표            | 진행 중인 목표를 종류별 카드로 확인    | A    |
| G-02  | 목표 상세         | 목표            | 목표 하나의 설정과 기록                | 없음 |
| G-03  | 목표 만들기       | 목표            | 새 목표 등록                           | 없음 |
| G-04  | 목표 보관함       | 목표            | 달성을 완료하거나 만료된 목표를 보여줌 | 없음 |
| S-01  | 일정              | 일정            | 하루 시간표와 TO-DO 관리               | A    |
| S-02  | 일정 · 할 일 추가 | 일정            | 일정과 할 일 입력                      | 없음 |
| ST-01 | 설정              | 설정            | 앱 설정                                | 없음 |

## 오늘 탭 (T-01, T-02)

[오늘 탭 시안](./reference/today.png)

오늘 할 목표를 한 화면에서 확인하고 바로 기록하는 시작 화면입니다.
위에서 아래 순서는 다음과 같습니다.

1. 헤더: 화면 이름 "오늘"과 날짜 (2026년 10월 20일 화요일)
2. 집사 한마디: 선택한 목표에 맞춘 격려 문구
3. 최근 14일 기록: 선택한 목표의 최근 14칸과 "14일 중 N일"
4. 목표 카드: 위에서 3개와 "목표 N개 더보기"
5. 하단 탭

### 동작

| 행동                                          | 결과                                                                                                  | 상태 |
|-----------------------------------------------|-------------------------------------------------------------------------------------------------------|------|
| 목표 카드를 누름                              | 위쪽 목표명 · 최근 14일이 그 목표의 기록으로 바뀜. 선택한 카드에 테두리가 생기고, 집사 한마디도 바뀜. |      |
| 처음 열었을 때                                | 목표 중 첫 번째가 디폴트로 선택된 상태                                                                |      |
| 기록 버튼 (+입력,+했어요)을 누름              | 집사 대사창(T-02)이 뜨고 그 목표가 선택됨. 목표의 최근 14일 중 가장 마지막 칸(오늘)의 상태가 바뀜.    |      |
| 대사창 닫기 버튼 또는 바깥 어두운 부분을 누름 | 대사창이 닫힘                                                                                         |      |
| "목표 n개 더보기"를 누름                      | 접혀 있던 목표가 펼쳐짐 (무한 스크롤)                                                                 |      |
| 스크롤을 내림                                 | 위쪽 최근 14일 기록은 그 자리에 그대로                                                                |      |

### 홈 화면 목표 카드 3종
| 목표                 | 화면에 보이는 것                                                  | 기록 버튼 |
|----------------------|-------------------------------------------------------------------|-----------|
| 먀의 투쟁 (누적형)   | 오늘 10/20쪽, 전체 220/734쪽 (30%), D-26, 오늘 분량 진행 바 (50%) | + 입력    |
| 금연 (반복형)        | 21일째, 9월 30일부터, '지키는 중'. 진행 바 없이 일수만 보여줌.    | 피웠어요  |
| 주 3회 운동 (빈도형) | 1/3회, '오늘 하면 이번 주 달성', 월~일 7칸 (월 한 날, 오늘 화)    | + 했어요  |

### 집사 대사*

집사 아이콘과 상황에 맞는 대사를 보여줍니다. RPG Maker / 쯔꾸르 게임의 대사창을 생각하시면 됩니다.

왼쪽에는 집사 아이콘, 오른쪽에는 대사를 보여줍니다. 대사창을 다시 누르거나 대사창 외의 화면을 누르면 닫힙니다.

## 목표 탭 (G-01, G-02, G-03, G-04)

[목표 탭 시안](./reference/goal-list.png)

[목표 상세 시안](./reference/goal-detail.png)

[목표 만들기 시안](./reference/goal-new.png)

[목표 보관함 시안](./reference/goal-archive.png)

진행 중인 목표 전체를 종류별 카드로 보는 목록 화면입니다. 위에서 아래 순서는 다음과 같습니다.

1. 헤더: 화면 이름 '목표' 와 '+ 목표 추가' 버튼
2. 전환: '진행 중 N' / '보관함'
3. 목표 카드 목록: 목표가 많아지면 스크롤
4. 하단 탭

카드는 목표 종류마다 보여 주는 것이 다릅니다. 화면에 나온 수치는 모두 예시입니다.

| 목표(종류)                            | 화면에 보이는 것                                                                                                              | 기록 버튼  |
|---------------------------------------|-------------------------------------------------------------------------------------------------------------------------------|------------|
| 카페인 하루 2잔 이하 (반복형, 줄이기) | 남은 여유 1잔, 오늘 1잔 마심 · 상한 2잔. 바는 오늘 남은 여유 (50%) 를 뜻함                                                    | + 마셨어요 |
| 체중 감량 (도달형, 줄이기)            | 현재 81.2kg, 목표 75.0kg, 시작 85.0kg부터 목표 75.0kg까지 진행 바 (38%), 이번 주 목표 라인 눈금 (81.0kg), '0.2kg 위에 있어요' | 체중 기록  |
| 금연 (반복형, 줄이기)                 | 21일째, 9월 30일부터                                                                                                          | 피웠어요   |
| 주 3회 운동 (빈도형, 주간)            | 이번 주 1/3회, 월~일 7칸                                                                                                      | + 했어요   |


### 목표 탭 동작
| 행동                              | 결과                          | 상태 |
|-----------------------------------|-------------------------------|------|
| 목표 카드를 누름                  | 목표 상세 탭이 열림           |      |
| + 목표 추가 버튼을 누름           | 목표 추가 탭이 열림           |      |
| 보관함 버튼을 누름                | 목표 보관함 탭이 열림         |      |
| 가장 아랫부분에서 한 번 더 스크롤 | 새 목표 추가 (목표 탭이 열림) | 제안 |

### 목표 상세*

목표 카드 하나를 누르면 나오는 상세 탭입니다. 목표 달성 현황과 현재 설정을 보여줍니다.

아래쪽에는 설정 수정 버튼이 있어야 합니다만, 화면 사이즈상 잘렸습니다 (...)
수정 예정.

### 목표 만들기

새로운 목표를 등록하는 화면입니다.

목표의 방향성과 종류를 고를 수 있습니다. 선택 이후 준비된 프리셋을 수정하거나 그대로 사용할 수 있습니다.

### 목표 보관함

만료된 목표를 보관하는 탭입니다.

만료된 목표를 삭제하거나 재시작할 수 있습니다.

## 일정 탭 (S-01, S-02)

[일정 탭 시안](./reference/schedule.png)

[일정 추가 탭 시안](./reference/schedule-add.png)

하루 단위 시간표와 TO-DO를 함께 관리하는 화면입니다.

기록 초안에 없던 기능을 새로 추가했으며, 시즌 1 개발 (v0.1) 에는 포함되지 않습니다.

1. 헤더: 화면 이름 "일정", 날짜, "+ 추가" 버튼
2. 주간 날짜 줄: 월~일 7칸 (화면에서는 19-25일), 오늘 (20일) 이 선택된 상태
3. 시간표: 07시-18시, 일정 블록과 '현재 시각' 표시선
4. TO-DO: 진행 바와 '2/5 완료', 체크박스와 체크 항목
5. 하단 탭

### 일정 탭 동작

| 행동                                       | 결과                                                       | 상태 |
|--------------------------------------------|------------------------------------------------------------|------|
| 시간표의 일정 블록을 누름                  | 일정 현재 설정 및 수정 탭이 열림                           |      |
| +추가 버튼을 누름                          | 새 일정 추가 탭이 열림                                     |      |
| 미완료 상태의 TO-DO 리스트 체크박스를 누름 | 해당 리스트 취소선 처리, 체크박스 채움, 완료 상태로 변경   |      |
| 완료 상태의 TO-DO 리스트 체크박스를 누름   | 해당 리스트 취소선 삭제, 체크박스 비움, 미완료 상태로 변경 |      |

### 일정 및 할 일 추가 탭

새 일정 블록 또는 TO-DO 리스트의 할 일을 추가하는 탭입니다.
