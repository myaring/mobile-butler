## 1. 요구사항 · 기능

| REQ    | 요구사항 (사용자가 원하는 것)                | FUNC    | 기능 (앱이 하는 일)                             | 우선순위 | 담당 | 상태    |
| ------ | -------------------------------------------- | ------- | ----------------------------------------------- | -------- | ---- | ------- |
| REQ-01 | 목표와 마감일, 목표치를 정하고 싶다          | FUNC-01 | 목표 등록 (이름·마감일·목표치 입력)             | 1        |      | 작업 전 |
| REQ-02 | 하루에 얼마나 해야 하는지 알고 싶다          | FUNC-02 | 하루 분량 자동 계산·표시                        | 1        |      | 작업 전 |
| REQ-03 | 오늘 한 만큼 기록하고 싶다                   | FUNC-03 | 오늘 한 분량 입력                               | 1        |      | 작업 전 |
| REQ-04 | 목표가 여러 개면 순서를 정하고 싶다          | FUNC-04 | 목표 우선순위 지정                              | 2        |      | 작업 전 |
| REQ-05 | 집사 성격을 골라 원하는 말투로 응원받고 싶다 | FUNC-05 | 집사 성격 선택 (표독형/안정형/불안형 등 중 1개) | 2        |      | 작업 전 |
| REQ-05 | 〃                                           | FUNC-06 | 성격별 말투로 문구 표시                         | 2        |      | 작업 전 |

## 2. 기능 상세

| FUNC    | 기능                | 흐름                                                                           | 이럴 땐?                                                                  | 완료 기준                                                      |
| ------- | ------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------- | -------------------------------------------------------------- |
| FUNC-01 | 목표 등록           | "목표 추가" → 이름·마감일·목표치 입력 → 저장하면 목록에 표시                   | 빈칸 있으면 저장 불가 / 지난 날짜는 마감일로 선택 불가                    | 등록한 목표가 목록에 보이고 수정·삭제할 수 있다                |
| FUNC-02 | 하루 분량 계산·표시 | 목표 등록 시 홈에 "오늘 할 분량" 표시                                          | 덜 하거나 더 하면 남은 날로 다시 계산 / 마감일 지나면 "기한 지남"         | 300쪽·30일이면 "하루 10쪽"이 보인다                            |
| FUNC-03 | 오늘 한 분량 입력   | 목표 선택 → 오늘 한 양 입력 → 남은 양·진행률 갱신                              | 0 이하·숫자 아니면 저장 불가 / 목표치 넘기면 "달성" 표시                  | 입력한 만큼 남은 양이 줄어든다                                 |
| FUNC-04 | 목표 우선순위 지정  | 목표 목록에서 목표를 길게 눌러 위아래로 옮김 → 위에 있을수록 먼저 표시         | 목표가 1개면 순서 변경 불가 / 새 목표는 맨 아래에 추가                    | 바꾼 순서가 홈과 목록에 그대로 보이고, 앱을 다시 켜도 유지된다 |
| FUNC-05 | 집사 성격 선택      | 처음 실행 시 집사 성격 고르기 (표독형/안정형/불안형 등) → 설정에서 언제든 변경 | 고르지 않고 넘기면 안정형으로 시작                                        | 고른 성격이 저장되고, 설정에서 바꾸면 바로 반영된다            |
| FUNC-06 | 성격별 말투 표시    | 홈 화면, 기록 완료, 목표 달성 같은 상황마다 선택한 집사 말투로 문구 표시       | 해당 상황 문구가 없으면 기본 문구 표시 / 같은 상황엔 문구 여러 개 중 랜덤 | 집사를 바꾸면 같은 상황에서 다른 말투 문구가 나온다            |
